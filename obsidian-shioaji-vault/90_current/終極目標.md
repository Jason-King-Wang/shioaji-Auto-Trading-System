# 終極目標

這個專案的最終目標，是把 `SinoPac Auto Trading / 永豐自動交易` 做成一個可公開分享的 execution dashboard / reporting site，同時保留對 private 上游私有選股訊號的邊界。

## 核心定位
- 這不是 `private_model_vault` 的主 上游私有選股模型頁。
- 這是永豐自動交易的執行儀表板與報告站。
- 若資料來源來自 上游私有選股模型，只能顯示 signal labels、來源、名單與結果，不能把 private 規則全文搬上網頁。
- 網頁的重點是讓人一眼看懂：今天掛了哪些單、目前買到哪些股、哪些還沒買到、整包表現如何、和台股加權 / 台積電相比如何。

## 網頁分層
- `reports/auto_trading/current.html`
  現在最新狀態的 current dashboard。
- `reports/auto_trading/daily/YYYY-MM-DD.html`
  每個交易日一頁的 daily close page。
- `reports/auto_trading/weeks/YYYY-MM-DD_YYYY-MM-DD.html`
  每週一頁的 weekly summary page。
- `reports/auto_trading/data/*.json`
  給前端和統一入口站讀取的 snapshot。
- `notes/daily/*.md`、`notes/weeks/*.md`
  給 Obsidian / Markdown 追蹤的文字版產物。

## Current Dashboard 必備內容
- 頂部總覽卡：week_id、trade_date、最後更新時間、mode、provider、weekly_budget、hard_budget、used_cash、remaining_cash、current_equity、策略報酬率、today status。
- 選股來源與訂版：預選 / 訂版 / source / include / exclude / provider。
- 買進執行區：掛了哪些買單、目標幾股、已買幾股、剩幾股、現在委託價多少、目前模式、下次檢查時間。
- 持倉區：持有股數、買進均價、成本、市值、未實現損益、估計出場金額。
- 賣出區：最後交易日的 can_sell、conservative_sell_price、profit、decision、remaining_qty。
- 整包分析：market_value、unrealized_pnl、conservative_profit、threshold、recommendation。
- 圖表：策略 vs 加權 vs 2330、現金 vs 已投入資金。
- 事件紀錄：掛單、取消、改價、成交、warning、API error。

## Daily / Weekly Page 要求
- Daily：整理今日預選 / 訂版、目標股數、實際買進、未成交 / expired_unfilled、取消重掛、持倉與損益、策略 vs 加權 vs 2330、錯誤 / 警告、明日待處理事項。
- Weekly：整理本週總表、benchmark 比較、逐日表、排除項目、實際交易成果、賣出執行結果、未成交 / expired_unfilled、下週調參建議。
- Benchmark 固定包含：台股加權與 2330 台積電。

## 更新節奏
- 盤中：09:00 - 13:30 每 5 分鐘刷新 current dashboard。
- 收盤後：產出 daily close page。
- 每週最後一個交易日收盤後：產出 weekly summary page。
- 每次更新都要同步產出 HTML / JSON / Markdown，並回寫 Obsidian。

## 目前還沒完全做到的部分
- 上游私有訊號 + LLM 的整包 live buy loop 還沒 fully live。
- 真實持倉驅動的 live sell loop 還沒 fully live。
- 報表內某些事件內容和 provider 名稱仍然保留技術字串，需要逐步再中文化 / 人性化。
- current dashboard 的資料仍以本機流程輸出為主，還沒有做更完整的互動式篩選 / 搜尋 / drilldown。

## 長期原則
- 不斷優化到可以把這份「終極目標」做好為止。
