## 定位
- 這個系統是 `private_model_vault` 的執行層
- 上游負責研究、模型、觀察與訊號
- 這裡負責把訊號轉成可控的委託、下單、回報與紀錄

## 層級
- `90_current` > `10_models` > `20_weeks`
- current 放現在要執行的內容
- long-form 放比較穩定的流程設計與風控原則
- weeks 放歷史問題、修正決策與回顧

## 主流程
1. 確認帳號 / API / CA 狀態
2. 準備要下的委託參數
3. 先 preview
4. 再 live submit
5. 回寫委託狀態與成交結果
6. 形成每日 / 每週檢討
