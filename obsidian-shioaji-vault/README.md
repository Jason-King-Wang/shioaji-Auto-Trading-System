# Obsidian Shioaji Vault

This folder is a sanitized Obsidian documentation package for the Shioaji auto-trading execution system.

It preserves the project notes, daily sync notes, weekly summaries, current operating manuals, and templates that explain the execution workflow.

Sensitive material is intentionally removed or generalized:

- Real account identifiers, personal email addresses, and broker credentials.
- Local absolute paths from the private workstation.
- Private upstream stock-selection model names, rule sources, and candidate-pool paths.
- Raw live-trading data, private reports, databases, logs, and certificate files.

The public boundary is the execution system: order planning, risk gates, broker reconciliation, workflow status, and operator documentation.
