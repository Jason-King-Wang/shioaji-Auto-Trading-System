# Obsidian Showcase

Curated documentation excerpts from the local model vault.

This folder is intentionally small. It demonstrates how the project documents model boundaries, execution layers, and review habits without publishing private stock-selection rules.

Included:

- `sell_model_core.md`: High-level sell-model boundary and calibration philosophy.
- `sell_execution_layers.md`: Execution-layer separation between prediction, manual execution, weekly exits, and automation.

Excluded:

- Private AB stock-selection rules.
- Candidate-pool construction rules.
- Daily private model outputs.
- Any credential, broker, account, or real-order data.
